# Writing My Own Code

I don't want to just know how to code. I want to be able to **think in code**.

This repository is where I learn programming by writing it myself — solving problems, making mistakes, debugging them, and understanding why the solution works.

No blindly copying. No relying on AI to do the thinking.

Just consistent practice, one piece of code at a time.
